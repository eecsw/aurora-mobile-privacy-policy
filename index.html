Om Aurora / About Aurora

SV
Aurora är en specialiserad mobilapplikation utformad för att installera och konfigurera trådlösa nödbelysningssystem.

Under installationen kan applikationen begära användarens Wi-Fi-nätverksuppgifter. Dessa uppgifter:

  • Överförs säkert via krypterad Bluetooth
  • Skickas direkt till nödbelysningsarmaturerna

Applikationen Aurora:

  • Lagrar inte någon information som tillhandahålls av användaren
  • Delar inte sådan information med tredje part

Informationen överförs enbart till nödbelysningsarmaturer som ingår i det smarta trådlösa nödbelysningssystemet. Det Wi-Fi-nätverk som används under installationen behöver inte ha en aktiv internetanslutning.

EN
Aurora is a specialized mobile application designed to establish and configure wireless emergency lighting systems.

During installation, the application may request the user's Wi-Fi network credentials. These credentials are:

  • Securely transmitted via encrypted Bluetooth
  • Sent directly to the emergency lighting luminaires

The Aurora application:

  • Does not store any information provided by the user
  • Does not share such information with third parties

The information is transmitted only to emergency lighting luminaires that are part of the smart wireless emergency lighting system. The Wi-Fi network used for the installation process does not need to have an active internet connection.

Dataanvändning och integritet / Data Usage and Privacy

SV
Aurora är engagerad i att skydda användarnas integritet. Applikationen ägnar sig inte åt:

  • Riktad reklam
  • Dataloggning
  • Anonym datainsamling
  • Datautvinning
  • Beteendespårning

Dessutom delas inga användaruppgifter med tredjepartstjänster som ägnar sig åt sådana aktiviteter.

EN
Aurora is committed to protecting user privacy. The application does not engage in:

  • Advertising targeting
  • Data logging
  • Anonymous data collection
  • Data mining
  • Behavioral tracking

Additionally, no user data is shared with third-party services engaged in such activities.
